Audit baseline: branch `skot-ideas` at `b2d47a2` plus the working tree as read on 21 Nov 2026. Rows marked **Done (this branch)** were implemented in the same pass, test first. Line numbers drift while those edits land; each cite also names the function or comment so it can be re-found with grep. ## Recommended S + high-impact items

Implemented in this pass: 1, 2 and 3 (3 is medium impact but a live bug and the base for paste / Alt-drag). Still open: 4 (S, medium impact) and 5 (needs a product OK because it moves the tone cycle off the arrow keys).

1. **Make Ctrl/Cmd+wheel and pinch zoom the canvas only (#1).** In `CV`, remove `onWheel={handleWheel}` (CV:1043) and add a `useEffect` that calls `containerRef.current.addEventListener("wheel", fn, { passive: false })`, with matching cleanup. Move the math in `handleWheel` (CV:365-390) into a pure `computeWheelViewport(viewport, { deltaX, deltaY, ctrlKey, metaKey }, cursor, { min: 0.28, max: 2.6 })` in `lib/geometry.ts`. Test in `lib/geometry.test.ts`: the world point under the cursor stays put after a ctrl-zoom; zoom clamps at both limits; a plain wheel only translates by `-deltaX/-deltaY`.
2. **Add zoom keys and fix the −/+ buttons (#2).** Add `zoomAroundPoint(viewport, factor, screenPt, min, max)` to `lib/geometry.ts`. In `onKeyDown`, just before `// Select all` (WS:2763), handle Ctrl/Cmd + `=`/`+` (zoom in), `-` (zoom out) and `0` (reset to zoom 1 around the screen centre), each with `preventDefault`. Also handle Shift+1 → `fitToView()`, matched on `e.code === "Digit1"` because `e.key` is `"!"`; this doesn't clash with the 1/2/3 prediction keys. Point the buttons at WS:3623 and WS:3642 at `zoomAroundPoint` with the screen centre so they stop drifting. Test in `lib/geometry.test.ts`: the centre's world point is unchanged after zoom in and out; reset returns `zoom === 1` with the same centre; clamping holds.
3. **Make duplicate rebind arrows (#6, and the base for Alt-drag #10 and paste #3).** Add `duplicateElements(sources, makeId, offset)` to a new `lib/clone.ts`. It clones every element, maps old to new ids, rewrites `fromId`/`toId` to the clone when the endpoint was also duplicated, and offsets `fromPoint`/`toPoint` and freedraw `points`. Replace the inline map in `handleDuplicateIds` (WS:2478-2500) with it. Test in `lib/clone.test.ts`: duplicating {A, B, A→B} gives a new arrow from A′ to B′; duplicating only the arrow keeps the original endpoints; ids are unique; ink points shift by the offset.
4. **Shift-constrain while drawing and resizing (#7).** Add `constrainBox(start, current, shift)` (square box from the larger side) and `snapAngle(start, current, stepDeg = 15)` to `lib/geometry.ts`. In `handlePointerMove`, save `e.shiftKey` on `drag` and apply the helpers in `draw_shape` (CV:682), `connect` (CV:672) and `resize` (CV:654-666, keeping the aspect ratio of `originBox`). `handlePointerUp` (CV:700, CV:840-853) reads the saved flag. Test in `lib/geometry.test.ts`: a drag to (100, 40) with shift gives 100×100; arrow angles snap to multiples of 15°; proportional resize keeps the ratio.
5. **Free the arrow keys for nudge (#8, needs a product OK).** In WS:2701-2730, keep `[` `]` for the tone cycle and drop `ArrowLeft`/`ArrowRight` from it. Add Arrow-key nudges of 1 px (Shift: 10 px) through a pure `nudgeElements(elements, ids, dx, dy)` in `lib/geometry.ts`: shapes move x/y, free arrows move `fromPoint`/`toPoint`, ink moves `points`, bound arrows are left alone because they follow their shapes. Commit with the default `recordUndo`. Test in `lib/geometry.test.ts`: each element kind moves correctly; unselected elements are untouched.
